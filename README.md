# 📋 Aplicação de Tarefas (To-Do List)

Este projeto é uma aplicação React moderna para o gerenciamento de tarefas cotidianas, desenvolvida como parte do **Desafio 2**. O objetivo principal foi consolidar os conceitos de rotas, gerenciamento de estado global, efeitos colaterais e persistência de dados.

## 🚀 Tecnologias Utilizadas
* **React** com **Vite** (Ambiente de desenvolvimento rápido)
* **React Router Dom (v6)** (Navegação entre múltiplas páginas)
* **Context API** (Gerenciamento de estado global sem Prop Drilling)
* **LocalStorage** (Persistência dos dados no navegador do usuário)

## 🛠️ Funcionalidades (CRUD)
* **Adicionar Tarefas:** Página dedicada com formulário e validação de campos.
* **Visualizar Tarefas:** Listagem dinâmica na página inicial (Home).
* **Atualizar Status:** Possibilidade de marcar/desmarcar tarefas como concluídas (com efeito visual riscado).
* **Excluir Tarefas:** Remoção ágil da lista de tarefas através de um botão dedicado.
* **Persistência automática:** As tarefas não somem ao atualizar a página (`F5`).

## 📦 Como Executar o Projeto Localmente

#### 1. Clone o repositório:
git clone [https://github.com/SEU_USUARIO/aplicacao-de-tarefas.git](https://github.com/SEU_USUARIO/aplicacao-de-tarefas.git)

#### 2. Entre no diretório do projeto:
`` cd aplicacao-de-tarefas``

#### 3. Instale as dependências necessárias:
`` npm install ``

#### 4. Inicie o servidor de desenvolvimento:
`` npm run dev ``

#### 5. Acesse no navegador:
Abra o endereço gerado no terminal (geralmente http://localhost:5173) para visualizar o projeto.
